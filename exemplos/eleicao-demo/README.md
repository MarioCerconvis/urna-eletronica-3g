# Eleição de demonstração

Mesmos dados fictícios do protótipo de 2016 (Turma da Mônica × Disneylândia), agora em um
manifesto JSON imutável. Para gerar as chaves, assinar o manifesto e simular uma eleição
completa (votar → verificar → apurar → boletim) use:

```bash
urna3g demo --saida /tmp/demo-urna
```
